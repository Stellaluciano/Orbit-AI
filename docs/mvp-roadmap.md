# MVP Roadmap

## Milestone 1
- Task submission endpoint.
- Deterministic planner output.
- Queue + executor heartbeat.

## Milestone 2
- Worker sandbox integration.
- Tool plugin registry.
- Artifact upload to object storage.

## Milestone 3
- Rich workspace UI with file tree and terminal.
- Real-time DAG status updates.
- Run budgeting, retries, and policy controls.
